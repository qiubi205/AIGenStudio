# AIGenStudio (AI Multi-Media Studio)

一款专注于 **语音克隆 (Voice Clone)**、**语音合成 (TTS)** 与 **AI 视频生成 (MiniMax H3 / Multi-modal Video Gen)** 的移动端创作工坊应用。

## 核心功能
1. **音色克隆工坊**：支持上传本地音频样本（10s~5min），调用 MiniMax Voice Clone API 快速复刻专属音色并保存管理。
2. **语音合成 (TTS)**：支持选择复刻音色或系统预设音色，调节语速、音调、音量、情绪标签、语气词，生成高清 MP3 并直接试听、分享与保存。
3. **视频创作工坊**：集成 MiniMax H3 视频生成接口，支持文生视频、首尾帧/图生视频及多模态参考生视频，支持任务轮询与实时下载。
4. **统一密钥与服务商管理**：本地保存 MiniMax 等平台 API 密钥，开箱即用。
